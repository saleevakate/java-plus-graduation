Микросервисное приложение для поиска и организации событий.

Инфраструктурные сервисы:
1. Discovery Server - регистрация и обнаружение сервисов. Порт 8761
2. Config Server - централизованное хранение конфигураций. Порт 8888
3. Gateway - единая точка входа, маршрутизация. Порт 8080

Бизнес-сервисы:
1. User Service - сервис работы с пользователями
2. Event Service - сервис работы с событиями, категориями, подборками
3. Request Service - сервис работы с заявками
4. Stats Service - сервис сбора статистики
5. Location Service - сервис дополнительной функциональности из группового проекта

Модуль core:
1. api-client - клиенты для взаимодействия между сервисами
2. common-api - хранилище моделей DTO
3. common-exception - глобальный обработчик ошибок
4. test-cleanup - модуль со скриптом очистки бд. Необходим только для тестирования, не подключен к config server

Так же прикреплена коллекция тестов postman.
